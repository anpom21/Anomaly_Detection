# Leg press mechanics project

This code is for the mechanics project were our group has made a leg press.
The main file in this project is located under the Interface folder, and its the GUI.py file.
This file runs the GUI for the project and calls all the relevant modules from other folders.
The game can be ran as an individual file using the file in the Interface/Game folder called flappy_bird.py. 
The file should be run from the interface folder. Ensure that all the required dependencies listed below are installed.

# Dependencies

The project is tested with python 3.10 and 3.12. The packages required can be found in "Interface/requirements.txt" or below here:
- pyserial
- pygame
- websocket-client
- websockets
- PySide6
- matplotlib
- numpy
- PyYAML
- pyqtgraph
- PyQt6

A python environment can be made with "python -m venv .venv". After activating the environment, the packages can be installed with pip install -r "Interface/requirements.txt".
